## 1. What this project is

Student opportunity discovery platform for **internships and adjacent student
opportunities** — hackathons, competitions, workshops, conferences. Primary
audience is Indian students; some global coverage.

**Scholarships, fellowships and standalone research grants are explicitly OUT of
scope** (owner's decision, 2026-07-31). Enforced by `OPPORTUNITY_SCOPE_TYPES` in
`backend/app/core/config.py` and `is_in_scope_opportunity()` in
`backend/app/services/scraper.py`. Removed from discovery keywords to save
SerpAPI/LLM credit.

Stack: FastAPI + MongoDB (Beanie ODM) backend in `backend/app`, Next.js 16
frontend in `frontend/src`. ~40k LOC Python, ~22k LOC TypeScript.

`~/Desktop` on 2026-07-28 because Desktop syncs to iCloud, which had evicted ~68%

**The folder name must stay byte-identical, including the space.** Docker Compose
derives its project name from it; renaming orphans the `ivyleague_*` volumes and
looks like total data loss. Consider adding `COMPOSE_PROJECT_NAME=ivyleague` to
`.env` before ever renaming.

### 2.2 Always start the app with the script
```bash
cd ~/Developer/"ivy league" && ./scripts/start_local_production.sh
```
`.env` contains a **live MongoDB Atlas connection string**. The start script
overrides it with local Docker (port 27018). Starting uvicorn by hand **without
those exports connects to production Atlas.** This already happened once on
2026-07-28 (~15:23–16:05 UTC) and a later audit created two test users there:
`sec.audit.a@example.com`, `sec.audit.b@example.com` — **still need deleting.**

Tell-tale: `/health/ready` Mongo latency ~2ms = local, ~60ms = Atlas.

## 5. What was fixed (and why it mattered)

### Ingestion was dead for 40 days — four independent causes
1. `system_metrics.py` subtracted naive from aware datetimes, raising *after* each
   successful scrape → job failed → 5 retries → dead. Silent, no alert.
2. `is_early_career_opportunity` ran seniority patterns over the **description**
   and before the allow-list; `\b[2-9]\+?\s+years?\b` matched inside `"0-2 years"`.
3. Past-deadline rows were **hard-deleted** on largely synthetic deadlines.
4. Internshala filled its budget in declaration order, so internship listings were
   never fetched (2 rows → 28).

### Other significant fixes
- **Event-loop binding** (`168a987`, `56d91e3`): module-level `asyncio.Semaphore`/
  `Lock` on singletons, while `fetch_page_sync` runs `asyncio.run()` per call.
  Killed every render-backed source. The real culprit was
  `SourceHttpClient._global_semaphore`, not the provider clients. Fixed with
  `LoopLocalSemaphore` / `LoopLocalLockMap` in `app/core/async_limits.py`.
- **SSRF** (`d4d63bf`): any user could make the server fetch `169.254.169.254`.
  Guard in `app/core/url_guard.py` — resolves DNS (literal-IP checks are
  bypassable), re-validates every redirect hop.
- **Logout didn't revoke** (`b464812`): with `AUTH_SESSION_REQUIRE_SERVER_STATE=false`
  a missing session read as valid. Now uses an explicit revocation tombstone.
- **Rate limiter failed open** (`e988e4e`): Redis outage silently disabled all
  limits. Auth paths now fail closed.
- **Non-posting gate** (`bb9c598`): 27.5% of the corpus was nav links, help
  centres, salary pages and newsroom articles. Gate catches ~13%; the rest are
  company careers *landing* pages needing a different rule.
- **Stipend was 0% populated**: `\b` cannot precede `₹`. Now validated against
  **8,483 real Internshala strings — 100% of rows that carry a stipend**.
- **`_fetch_in_thread` returned a Future**, but `create_task` needs a coroutine.
  I introduced this in `28a3cdd` and it broke every scheduled run. Fixed `0f42d19`.
  **Lesson: verify through the batch path, not by calling scrapers directly.**

news.columbia.edu and wellfound both 403 → 200.
